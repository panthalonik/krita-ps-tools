Camera Raw Filter (Krita PS)

Filter > Camera Raw Filter… (Shift+Ctrl+A) adds a Camera Raw Filter filter mask to the active layer – like a Smart Filter it can be changed later (select it and press Shift+Ctrl+A, or use the Properties panel). The adjustment layer menu has Camera Raw… as a layer that works on everything below.

  • Light: Exposure, Contrast, Highlights, Shadows, Whites, Blacks, Auto; Curve – parametric (Highlights / Lights / Darks / Shadows and the split points) and point curves (RGB, Red, Green, Blue).
  • Color: White balance (As Shot / Auto / Custom, Temperature, Tint, "Neutral = foreground colour"), Vibrance, Saturation; Color Mixer (Hue / Saturation / Luminance of 8 colours); Color Grading (wheels for Shadows, Midtones, Highlights, Global; Blending, Balance).
  • Effects: Texture, Clarity, Dehaze; Vignette (Highlight Priority / Color Priority / Paint Overlay, Amount, Midpoint, Roundness, Feather, Highlights); Grain (Amount, Size, Roughness).
  • Detail: Sharpening (Amount, Radius, Detail, Masking), Noise Reduction (Amount, Detail, Contrast), Color Noise Reduction (Amount, Detail, Smoothness).

The window looks like Adobe Camera Raw: the preview on the left (Fit / zoom, mouse wheel, double-click = Fit / 100%, drag to pan), the histogram, Edit (Auto, B&W, Profile) and the collapsible panels on the right, each with an eye that switches its effect off. Double-click a slider to reset it; \ or P = before / after. The results are close to Camera Raw, not identical (Adobe's algorithms are not public). In a PSD the layer is saved as pixels.

Color panel and Color Picker (Photoshop-style)

Settings > Dockers > Color (PS): foreground / background squares, the saturation / brightness field and the hue strip. Click the other square to edit it here; click the active square for the Color Picker (H S B, R G B, L a b radio buttons choose what the strip shows; C M Y K and # fields; Only Web Colors; Add to Swatches). Under the squares: black / white defaults and swap. Swatches: click = foreground, Ctrl+click = background, Alt+click = remove.

Blend If and Masks (Photoshop-style)

Blend If: right-click a layer, then Blend If…. The "This Layer" and "Underlying Layer" sliders work like in Photoshop. Alt + drag half of a slider to split it for a smooth transition. The canvas updates live while you drag.

  • The effect is a transparency mask named Blend If (…). Its settings are stored in the name, so don't rename it or paint on it.
  • Krita PS: Blend If is part of the compositing engine – it is computed while the image is drawn, from the real pixels of the layer and of everything below it, exactly like Photoshop. It updates live while you paint or move the sliders, and nothing below needs refreshing (the auto-refresh described next is only used in the official Krita).
  • Auto-refresh (official Krita): when you paint (or change, show/hide, move layers) below or on a layer with Blend If, the plugin recomputes it by itself right after you lift the pen (about 0.3 s) – never during a stroke or while a dialog is open. Only what the result really depends on triggers it: the layer's own pixels for This Layer, anything below it for Underlying Layer; painting the layer's own mask or layers above it does not. The image below is rendered on a hidden copy of the document, so the canvas does not flash. Layers above a Color Lookup / Selective Color layer don't show a stroke made below it until you lift the pen. Turn it off in Tools → Scripts → Auto-refresh Blend If / Adjustments. Tools → Scripts → Refresh Blend If / Adjustments refreshes everything at once.
  • Supports 8- and 16-bit RGB and Grayscale images.

Clipping mask: Alt + click the line between two layers in the Layers docker, or press Ctrl+Alt+G (taken over from Krita's Quick Ungroup), or right-click and choose Create / Release Clipping Mask.

  • Krita PS: clipping is part of the engine, exactly like Photoshop. Krita's Inherit Alpha switch (shown as Clipping Mask) is the clipping mask: the layer is clipped to the nearest unclipped layer below it in the same group, the stack is drawn on its own (clipped adjustment layers change only the base) and the base's blending mode applies to the whole stack. No hidden groups – layers can be moved, grouped and merged freely, and PSD files keep the clipping. "(clip)" groups of older documents are taken apart when the document is opened (the result looks the same).
  • Krita PS: new groups (Ctrl+G, New Group) are Pass Through, like in Photoshop – adjustment layers and Blend If inside a group work on everything below it. A layer can be clipped to a group (also a group inside a group): it clips to the group's content, and that group is then drawn isolated, exactly as Photoshop does. Releasing the clipping makes it Pass Through again. Blend If on a group works the same way: the whole group is faded as one layer.
  • A layer dragged into or created inside a stack (or created while a clipped layer is selected) is clipped automatically. A clipped layer dragged out of its stack is released.
  • Official Krita: the plugin builds a "base (clip)" group whose clipped layers use Inherit Alpha. The base's blending mode moves to the group.

Masks

  • The button with a circle at the bottom of the Layers docker adds a mask (from the selection, if any). Alt + click adds a black mask.
  • Alt + click a mask shows it on the canvas in grayscale. Alt + click it again (or select another layer) to go back.
  • Ctrl+Shift+V while a mask is selected pastes the image into the mask. It comes in with Transform handles; press Enter to apply. Ctrl+Z undoes it. With a layer selected, Ctrl+Shift+V pastes into that layer. Plain Ctrl+V is Krita's regular paste (new layer).
  • Levels (Ctrl+L), Curves (Ctrl+M) and other filters work on the selected mask.

Adjustment layers: the half black / half white circle button at the bottom of the Layers docker opens the same list as Photoshop. The layer is added above the active layer (with a mask from the selection, if any). The Properties panel (Settings → Dockers → Properties) shows its settings live: Levels (with histogram), Curves, Brightness/Contrast, Exposure, Hue/Saturation, Color Balance, Black & White, Photo Filter (PS presets), Color Lookup, Selective Color, Posterize, Threshold, Grain, Clarity and Solid Color. Gradient, Pattern and Gradient Map open Krita's own editor.

  • Panel buttons: clip to the layer below, Blend If…, Krita editor…, reset, visibility, delete.
  • Blend If on an adjustment layer limits the adjustment to a tonal range, like in PS. It is stored in the layer's own mask. You can still paint that mask by painting on the adjustment layer; the plugin combines your painting with Blend If when you select another layer.
  • Masks on adjustment layers: the mask button (or Krita's own "Add transparency mask") gives an adjustment layer an ordinary transparency mask. Paint on it to hide or reveal the adjustment, like in PS; the image updates while you paint. (Krita puts adjustment layers on the "Copy" blending mode, where a mask would cut a hole in the whole image, so the plugin switches such a layer to "Normal". Documents saved with older versions of the plugin are converted when opened.)
  • Curves needs Krita 5.3 or newer. On older versions use "Krita editor…".
  • Brightness/Contrast (with Use Legacy) and Exposure (Exposure, Offset, Gamma Correction – computed in linear light like Photoshop) are made as Photoshop's tone curve on a Krita curves filter layer, so they render natively and update live. Layers made with older versions of the plugin are converted when you select them. On Krita older than 5.3 they fall back to a Levels approximation.

Color Lookup (3D LUTs: .cube, .3dl, .look) and Selective Color (Reds … Blacks, Cyan/Magenta/Yellow/Black, Relative/Absolute – the Photoshop formula). In Krita PS these are real filter layers (C++ filters) – rendered live by Krita like any other adjustment, with the LUT stored in the layer itself (the .kra opens on another computer without the LUT file). Layers made in the official Krita are converted automatically when the document is opened. Such documents need Krita PS for these layers. In the official Krita there are no filters for these, so the plugin computes them: the layer is a paint layer whose pixels are made from the image below it, and it is recomputed automatically when something below changes (see Auto-refresh above). Opacity, blend modes, masks, clipping and Blend If work as on any layer. Don't paint on these layers – the next refresh replaces their pixels.

  • LUT list: the LUTs bundled with the plugin, Photoshop's Presets\3DLUTs folder (found automatically) and your own folders (LUT folders… in the panel). Load 3D LUT… opens any file (its folder is added to the list).
  • The LUT file path is saved in the .kra; if the file is missing (other computer), a LUT with the same name in your LUT folders is used.
  • 8-bit, 16-bit and 32-bit float RGB images. A small native module (ps_native.dll) does the math; a 6-megapixel image takes about 0.2 s.

Smart Objects: right-click a layer (or several selected layers) → Convert to Smart Object. The layers are saved into their own .kra file in a folder "document name Smart Objects" next to your document and replaced by a File Layer with a Transform mask.

  • Ctrl+T on the smart object transforms it without losing quality (Krita's Transform tool edits its Transform mask automatically) – scale it down and up again as often as you like.
  • Double-click the thumbnail (or right-click → Edit Contents) opens the contents in a new tab. Save it with Ctrl+S and the smart object in the main document updates by itself.
  • Ctrl+J on a smart object makes another instance of the same contents – editing the contents updates all of them, like in Photoshop.
  • The document must be saved first (the plugin asks). When you move or send the .kra, take the "Smart Objects" folder with it.
  • To turn a smart object back into pixels: right-click → Convert → to Paint Layer.

Side strip (like Photoshop's collapsed panels): a narrow strip between the canvas and the dockers with two buttons, Brushes (Krita's brush presets, F6) and Brush Settings (Krita's brush editor, F5). They open right next to the strip; click the button again, or click on the canvas, to close them. Right-click the strip to turn auto-collapse on or off. The strip hides in canvas-only mode (Tab). You can now close the Brush Presets docker to save space.

Tip: to stop Krita asking about the color profile on every paste from other apps, set Settings → Configure Krita → General → Miscellaneous → "Pasting data from other applications" to Assume sRGB.

Diagnostics: the plugin writes a small log to ps_tools.log in the Krita resource folder (Settings → Manage Resources → Open Resource Folder).

Brush Preset Picker (Photoshop-style)

In the tool options bar, the plugin puts a button with the current brush thumbnail and size in place of Krita's Edit brush settings and Choose brush preset buttons (it also hides the toolbar Size slider). The Brush Editor opens from the button under ⚙ in the panel, or with F5. Click it to open a panel like Photoshop's Brush Preset Picker:

  • Size and Hardness sliders (or type a value). Hardness is the Fade of a round or square (auto-brush) tip, the same as Brush Editor → Brush Tip → Fade. Like in Photoshop, it is disabled for image tips. Changing it marks the preset as changed, just like editing it in the Brush Editor; Krita's Reload button restores it.
  • Search Brushes filters by name; Enter picks the first match. The drop-down below filters by Krita's preset tags.
  • The row of recent brushes remembers the size you used with each of them.
  • Click a preset to use it, double-click or press Enter to use it and close the panel. The slider at the bottom changes the thumbnail size; drag the corner to resize the panel.
  • ⚙ menu: list or thumbnails-only view, show/hide tags and recent brushes, show Krita's Size slider or its brush preset / editor buttons again, clear recent brushes.
  • Mouse wheel over the toolbar button changes the brush size.
  • Tools → Scripts → Brush Preset Picker (at cursor) opens the panel at the mouse cursor. Give it a shortcut in Settings → Configure Krita → Keyboard Shortcuts.

Shift + drag: straight brush strokes (Photoshop-style)

With the Freehand Brush tool, hold Shift and paint: the stroke is locked to a horizontal or vertical line, depending on the direction of the first few pixels. Pressure, tilt and other pen data are kept.

Works with the mouse and with the tablet pen.

  • One-time setup: Krita must paint while Shift is held. In Settings → Configure Krita → Canvas Input Settings → Tool Invocation, add (or change) a shortcut: Mouse Button, input Shift + Left Button, action Activate.
  • Turn it on/off in Tools → Scripts → Shift + drag: brush strokes along X / Y or from the right-click menu of the Photoshop-style toolbox.

Tools (Photoshop-style) docker

A compact toolbox with tools grouped like in Photoshop: Move/Transform | Marquee, Lasso, Magic Wand | Crop, Assistants/References, Eyedropper/Measure | Smart Patch, Brush, Gradient/Fill | Pen, Text, Shape Selection, Shapes | Hand, Zoom. Tools from other plugins go to "Other".

  • Show it with Settings → Dockers → Tools (Photoshop-style) and drag it to the left edge.
  • Click a group to use the tool it shows. Press and hold, or right-click, to choose another tool of the group (shortcuts are listed). The group remembers the last tool you used.
  • Right-click on the empty part of the docker: one or two columns, button size, show/hide Krita's own Toolbox, Shift axis lock on/off.

Opacity / Flow / Smoothing in the tool options bar

In place of Krita's Opacity slider the plugin shows Photoshop-like fields: Opacity, Flow and Smoothing. Type a value, click ▾ for a slider, or drag the label left/right.

  • Smoothing sets the Freehand Brush tool's Brush Smoothing (Tool Options): 0% = None, more = Weighted with a larger distance (100% = 300 px). In Krita 5.3+, which has two distance sliders (at max / min speed), the value sets the larger one; the other follows if the two are chained with the lock button, otherwise it gets the same value. The ⚙ next to it switches to Stabilizer and opens Tool Options for the remaining settings. It is enabled once the Freehand Brush tool has been selected.
  • Right-click a field: show Krita's Opacity slider again.

Photoshop-style Layers docker

Krita's Layers docker shows clipping stacks and layer masks the way Photoshop does:

  • Clipping stacks look like in Photoshop: the base layer is underlined, the clipped layers above it are indented with a clipping arrow. (Official Krita: the plugin's "… (clip)" groups have no row of their own.)
  • A layer's transparency mask is shown as a second thumbnail next to the layer thumbnail instead of a separate row. Click it to edit the mask, click the layer thumbnail to edit the layer; the edited one has a frame. Shift+click the mask thumbnail = disable/enable the mask, Alt+click = show the mask alone.
  • Other masks (filter masks, extra transparency masks, Blend If) keep their own rows.
  • Only the look changes: eye, lock and alpha icons, drag & drop, renaming and the right-click menu are Krita's own. Turn it off in Tools → Scripts → Photoshop-style Layers docker look.

Clipping masks and Undo

  • Create / Release Clipping Mask is one undo step: one Ctrl+Z undoes it completely (Krita PS: Krita's own clipping switch; official Krita: Krita's Quick Group, Quick Ungroup and Move Layer Down commands on the selected layers). Releasing a clipped layer also releases the clipped layers above it, like Photoshop.
  • Grouping a base layer together with its clipped layers (Ctrl+G) keeps the clipping inside the new group, like in Photoshop. Releasing a layer inside such a group unclips it in place.
